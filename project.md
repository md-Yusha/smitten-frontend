# 💕 Smittenz — Privacy-First Couple Vault

> A secure, private digital space built exclusively for two.

Smittenz is a privacy-first mobile application designed for couples to communicate, store, and relive their most personal memories in a highly controlled and protected environment. Built on three core principles: **Privacy**, **Emotional Connection**, and **Data Security**.

---

## ✨ Features

### 🔒 Secure Chat
Real-time messaging with full privacy controls:
- Text, image, video, GIF, and emoji support
- Disappearing messages (24h / 7 days / 90 days)
- Sticker & GIF integration via Tenor / Klipy
- Quick-action message shortcuts (e.g. "Good night", "On my way")

### 🗄️ Private Vault
Each partner gets their own personal media vault:
- **My Vault** — full upload and management control
- **Partner Vault** — view-only access
- Secure streaming (no downloads, no file access)

### 🛡️ Advanced Privacy & Security
- End-to-end encryption (AES-256)
- Zero admin/server access to content
- Screenshot prevention (Android) & masking (iOS)
- No download or file export capability
- Media inaccessible via device storage

### 📅 Calendar Memory System
Turn special moments into a relationship timeline:
- Attach memories (image + description) to specific dates
- Highlighted calendar days
- "Our Journey" timeline view on dashboard

### 🔑 Data Control & Revocation
- Revoke partner access at any time
- Delete personal vault independently
- Mutual deletion triggers permanent data removal

### 🧮 Hidden App Mode *(Privacy Enhancement)*
- App disguises itself as a calculator or notes app
- Unlocked via a secret code

### 🚨 Panic Mode *(Privacy Enhancement)*
- One tap switches to a fake interface
- Designed for privacy in public situations

### 💳 Subscription & Payments
- Weekly and monthly plans
- Payment via **Cashfree** and **PhonePe**
- Instant confirmation and automatic activation

---

## 🚀 How It Works

```
1. Sign up with email & password
2. Subscribe via Cashfree / PhonePe
3. Generate and share an invite link or code
4. Partner joins using the link/code
5. Both users are securely connected (one partner only)
6. Start chatting, storing memories, and building your vault
```
