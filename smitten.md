Smittenz
Privacy-First Couple Vault
Complete Project Overview & Feature Explanation
________________________________________
1. Introduction
Smittenz is a secure, privacy-first mobile application designed for couples to privately communicate, store, and relive their personal memories in a highly controlled and protected environment.
The platform is built around three core principles:
•	Privacy
•	Emotional Connection
•	Data Security
All shared content — including messages, photos, and videos — remains accessible only between the two connected partners.
Unlike traditional messaging or cloud storage platforms, Smittenz is designed with a privacy-first architecture, where:
•	Media cannot be downloaded
•	Screenshots are restricted
•	Data is encrypted end-to-end
•	Even system administrators cannot access user content
This makes Smittenz a trusted private digital space for couples.
________________________________________
2. How the Application Works
Smittenz follows a simple and secure user flow:
1.	User signs up using email and password
2.	User subscribes via online payment (Cashfree / PhonePe)
3.	User receives an invite link or code
4.	Partner joins using the link/code
5.	Both users are securely connected (one partner limit)
6.	Each partner gets a personal vault
7.	Users can chat, store memories, and view shared content
All data is encrypted, access-controlled, and securely streamed.

3.3 Advanced Privacy & Security
Smittenz is built with strict privacy enforcement.
Key Capabilities:
•	End-to-end encryption (AES-256)

•	Media inaccessible via device storage
